# arc42-Template (DE) – aufgeteilt in 12 Kapitel

Dies ist das offizielle deutsche arc42-Template (Version 9.0-DE, Stand Juli 2025),
1:1 aufgeteilt in die 12 Standard-Kapitel-Dateien. Enthält die originalen
Erläuterungen (Inhalt/Motivation/Form) als Ausfüllhilfe – ersetze die
Platzhaltertexte (`<...>`) durch deine eigenen Inhalte.

Quelle: https://arc42.org (Original-Download)

## Vorgehen

1. Kopiere diesen Ordner als `docs/arc42/` in dein Repo (oder benenne ihn entsprechend um)
2. Arbeite Kapitel für Kapitel durch und ersetze die `<Platzhalter>`
3. Die Hinweistexte (Inhalt/Motivation/Form/Weiterführende Informationen) kannst du
   nach dem Ausfüllen löschen oder als Kommentar stehen lassen – deine Entscheidung
4. Bilder/Diagramme (referenziert über `images/...`) musst du selbst ergänzen,
   z.B. als Mermaid-Diagramme direkt im Markdown statt der `<figure>`-Verweise
